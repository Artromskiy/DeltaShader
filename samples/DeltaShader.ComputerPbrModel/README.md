# Computer PBR model

This sample is the mesh/material companion to `DeltaShader.ComputerPbr`.
It contains the supplied Sci-fi Military Rugged Laptop glTF asset and a
producer-side PBR shader pair named `computer-pbr-model`.

The vertex stage consumes the generated single vertex binding layout:

- location 0: `Position` (`float4`)
- location 1: `WorldNormal` (`float3`)
- location 2: `Uv0` (`float2`)
- location 3: `Tangent` (`float4`)

The generated byte offsets are `0`, `16`, `28`, and `36`; the vertex record
stride is `52` bytes.

The fragment stage samples the six laptop material maps declared in
`assets/README.md`. It combines normal mapping, metallic/roughness response,
ambient occlusion, direct lighting, and emissive contribution through static
PBR helpers. The generated `ShaderAbi`, vertex packer, and push-constant
packer are the only layout source for a consumer.

Build/publish from the DeltaShader repository:

```sh
./eng/prepare-compiled-shaders.sh
```

The published pair is named from the generated program
`ComputerPbrTexturedCompositeGraphicsShaderProgram` and is placed in
`src/DeltaShader/CompiledShaders/` with `.spv`, `.glsl`, and `.shader.json`
files.

The current DeltaRender headless smoke is intentionally not used for this
pair: it supports descriptor-free fullscreen draws only. A real model render
still belongs to the consumer path, which must load the glTF, repack its
vertex streams according to `VertexAbi`, bind the six sampled textures, pack
`ComputerMeshFrame`, and issue the indexed draw.
