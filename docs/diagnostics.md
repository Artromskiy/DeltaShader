# Diagnostics

Набор первичных кодов диагностики:

- `DSH001` — неподдерживаемая конструкция
- `DSH002` — неподдерживаемый тип
- `DSH003` — неподдержанный вызов метода
- `DSH004` — некорректный entry point
- `DSH005` — конфликт descriptors/specialization id
- `DSH006` — unsafe buffer layout
- `DSH007` — capability/feature вне профиля
- `DSH008` — recursion or invalid call graph
- `DSH009` — unsafe conversion
- `DSH010` — недетерминированная семантика
