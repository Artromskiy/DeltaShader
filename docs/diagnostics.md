# Diagnostics

Набор первичных кодов диагностики:

- `GLSH001` — неподдерживаемая конструкция
- `GLSH002` — неподдерживаемый тип
- `GLSH003` — неподдержанный вызов метода
- `GLSH004` — некорректный entry point
- `GLSH005` — конфликт descriptors/specialization id
- `GLSH006` — unsafe buffer layout
- `GLSH007` — capability/feature вне профиля
- `GLSH008` — recursion or invalid call graph
- `GLSH009` — unsafe conversion
- `GLSH010` — недетерминированная семантика
